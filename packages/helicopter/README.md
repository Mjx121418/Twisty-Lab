# Experimental Helicopter Cube package

`definition.json` contains only abstract placements, resources, ports, guards, and transports. `review.json` pins its semantic digest and supplies shape symmetries and published acceptance counts for the headless verifier.

See [the model specification](../../docs/helicopter-model.md) for scope, exact authoring, stop notation, verification, and remaining review and geometric integration work. Regenerate deliberately with `python3 scripts/helicopter_model.py --write`; the default command checks without changing these files.
